# eInk displej WeAct 2.13" BWR (3C)
Repozitář hodlám využít pro shromáždění podkladů ohledně připojení e ink zobrazovače k Arduinu. Rád bych dosáhl toho, aby výsledkem byl funkční projekt, kdy nějaké klasické Arduino, STM nebo RP2040 (asi ale s I/O 3.3V) bude schopné obsluhovat e ink displej 2.13" b/w/r od WeAct.

![Můj modul](https://github.com/WeActStudio/WeActStudio.EpaperModule/blob/master/Images/1.png?raw=true)

[Vzorová aplikace pro eInk WeAct připojený k ESP32](https://github.com/WeActStudio/WeActStudio.EpaperModule/blob/master/Example/EpaperModuleTest_Arduino_ESP32/EpaperModuleTest_Arduino_ESP32.ino)<br>
V kódu je třeba zrušit komentář (//) u řádku se správnou definicí připojeného displeje.
